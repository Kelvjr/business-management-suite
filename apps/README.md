# Apps

Target frontend products for the modular SaaS ecosystem:

- `sales`: standalone Sales Tracker SaaS/template.
- `expenses`: expense, profit, and margin product.
- `invoices`: invoice and receipt generator.
- `crm-lite`: lightweight customer relationship product.
- `reports`: analytics and exportable reports product.
- `business-os`: combined flagship suite.

The current runtime app remains in `apps/sales-tracker` until Phase 1 and Phase 2 migrations move code incrementally.
